# v2.0 Testing Checklist

Test in this order:

1. Home screen
   - START works

2. Choose Game
   - Work works
   - Family works
   - Friends works
   - Back works

3. Work
   - Industry selection works
   - After choosing an industry, Add Some Fun screen appears

4. Optional Packs
   - Can select multiple packs
   - Can unselect packs
   - SKIP works
   - NEXT works
   - Work mode also sees this screen

5. Players
   - Add player works
   - Player name capitalization looks correct
   - Select / unselect works
   - Selection persists during setup

6. Game Time
   - Game length changes
   - Question timer changes
   - Voice On / Off works
   - NEXT works

7. Ready
   - Summary looks correct
   - PLAY works

8. Ready Player
   - Player name visible
   - 3–2–1 countdown visible
   - Pause works
   - Mic toggle visible

9. Question
   - Player name is not clipped
   - Question is readable
   - Timer is not clipped
   - Round is visible
   - Voice can recognize an answer
   - Timer continues until correct answer or timeout

10. Result
   - Correct / Wrong / Timeout is readable
   - Correct answer is large
   - Current standings show Correct / Wrong / Timeout
   - Screen remains long enough to understand

11. Fairness
   - When game time expires, game finishes the current full round
   - Every player receives the same number of questions

12. Final Results
   - Winner appears
   - PLAY AGAIN works
   - MAIN MENU works
