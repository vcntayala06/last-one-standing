# Last One Standing — Clean Rebuild Build 1

This is a clean foundation, not a patch on the old app.

## What is included
- Home screen
- Work / Family / Friends / Solo modes
- Work-type selection
- Optional fun-category selection
- Player setup
- Game Time
- Voice Recognition ON / OFF
- Silent play: when Voice is OFF, a typed answer field + Submit button appears automatically
- Ready to Play
- One shared Next Player screen
- Timed questions
- Voice answer recognition
- Manual Correct / Wrong / Time Out controls for testing and hosting
- Results screen
- Centered scorekeeper ribbons
- Basic end-game screen
- Portrait + landscape responsive layouts

## Deliberately NOT included yet
- Browser text-to-speech announcer
- Music
- Final Showdown / Final Challenge rapid-fire logic
- Commercial artwork
- Question-pack expansion
- Save/resume

Those come only after the core loop is verified stable.

## Deployment
This build uses plain HTML/CSS/JavaScript with no build step or dependencies.
Copy the contents to the root of the GitHub Pages repository and push.
