# Last One Standing — Clean Build 3.7

Full replacement build based on Clean Build 3.6.

## Build 3.7 changes
- Player name is truly centered to the full screen width in the top zone, independent of Pause and volume controls.
- "NEXT PLAYER" is replaced with "IT'S YOUR TURN".
- You're Up -> Question now has an actual 1.8 second game-show visual transition plus an original transition sting.
- Result -> next You're Up now has an actual 1.8 second transition plus sound.
- Elimination / Final Showdown transitions are slightly more dramatic and longer.
- Question timer does not begin until the transition finishes.
- Existing 3.6 timer behavior, timeout buzzer, strike system, voice name/spelling controls, portrait hierarchy, and landscape reference layout are retained.
