# Release Notes — v2.0 Foundation

## Purpose
Replace the patch-heavy prototype architecture with one clean foundation.

## Major changes
- New router-based setup flow
- New persistent state/storage layer
- New modular question engine
- New voice engine
- New game engine
- New modular question JSON structure
- New reserved-zone question screen
- Optional fun packs are now part of Work, Family, and Friends setup

## Not included yet
- Large-scale question expansion
- Sound design / music
- Animations / confetti
- Admin mode
- Analytics
- Online multiplayer

Those belong to future releases after the foundation is verified.
