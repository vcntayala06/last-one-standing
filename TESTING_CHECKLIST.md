# Clean Rebuild Build 1 — Acceptance Checklist

Test in regular browser first, then the Home Screen app.

1. Home loads every time.
2. Choose Work, Family, Friends, and Solo without blank screens.
3. Game Time in landscape:
   - all three setting sections are visible or comfortably fit
   - Voice OFF / ON are centered
   - CONTINUE is fully visible and tappable
4. Ready to Play:
   - PLAY is visible in landscape
5. Next Player:
   - name is large and centered
   - YOU'RE UP / GET READY / countdown do not overlap
   - first player and later players use the same layout
6. Question screen:
   - question is visually dominant
   - timer is not clipped
7. Answer matching:
   - exact answer works
   - leading 'the/a/an' difference works
   - one small speech-to-text typo on normal-length answers can work
   - clearly wrong answers do not work
8. Result screen:
   - answer is readable
   - CURRENT STANDINGS appears
   - the ACTUAL '1. Name / Correct / Wrong / Timed Out' ribbon is centered
9. Play several turns:
   - scores update
   - player order rotates
   - no blank screen

10. Silent play:
   - With Voice ON, no keyboard answer box appears.
   - With Voice OFF, Type your answer + Submit appears.
   - Pressing Enter also submits.
   - Correct typed answers score correctly.
   - Wrong typed answers do not end the question; the player can keep trying until time expires.
   - The timer continues while typing.
