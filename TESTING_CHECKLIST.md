# Clean Build 3 Testing Checklist

1. Home / Page 1
   - Landscape still looks good.
   - Portrait is balanced.
   - After first tap, game-show music begins.
   - Say "Start Game" if voice permission allows it.

2. Voice setup
   - Say Work / Family / Friends / Solo.
   - Work type can be selected by voice.
   - Add Some Fun accepts category names, Skip, Continue.
   - Game Time accepts Quick Game, time choices, Continue.
   - Ready accepts Play / Start Game.

3. Player screen
   - Portrait is comfortable.
   - Landscape is not crunched.
   - Previously used names appear as autocomplete suggestions.

4. Rotate phone
   - Landscape to portrait and back several times.
   - Screen should redraw without needing a tap.

5. Question screen
   - Question on top.
   - Voice Active / Listening and Your Answer side by side.
   - Large countdown underneath.
   - Recognized answer text is easy to read.

6. Pause
   - Say Resume.
   - Say Leave Game.
   - Say End Game.
   - Heard text should display.

7. Quick Game
   - Select Quick Game.
   - Complete five questions.
   - Confirm the real ending appears.
