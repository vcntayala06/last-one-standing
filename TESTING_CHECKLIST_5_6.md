Core rule: if you can tap it, try saying it.

1. Verify BUILD 5.6.
2. On each setup screen, say the exact visible button labels.
3. Also try: click/choose/select/pick/press + button name.
4. Continue aliases: Start, Begin, Next, Go ahead, Let's go, I'm ready, Move on.
5. Category buttons: say Music, Sports, Geography, etc.
6. Player screen: Add player Joe; Change player two to Todd; Delete player three; Remove Maria.
7. Time screen: say visible time choices and Continue.
8. Ready screen: Start / Let's begin / I'm ready.
9. During gameplay: Pause; Pass; spoken answers.
10. Pause screen: say any visible control.
11. Watch footer feedback: LISTENING, HEARD, and green action confirmation.
12. Run several consecutive questions and verify recognition recovers if Safari stops it.
13. Verify all 5.5 gameplay behavior still works.
