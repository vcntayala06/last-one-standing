# v2.0.9 Landscape Polish

This release keeps the improvements from v2.0.8 and focuses on the remaining landscape blockers.

- Add Some Fun: Skip and Continue fully visible in a dedicated action row.
- Game Time: Continue fully visible; settings area scrolls independently.
- Ready to Play: compact game-summary card so Play can fit without scrolling on normal landscape phones.
- Current Standings: removes the previous translate-based centering and centers the actual tracker/ribbon and scoreboard with auto margins.
